# Bundled Inter fonts

Sona bundles the unchanged Inter 4.1 static upright Regular (400), SemiBold (600)
and Bold (700) fonts by Rasmus Andersson. Inter is licensed under SIL Open Font
License 1.1; the complete upstream license is included in LICENSE.txt. These fonts
are application resources, never installed into the operating system.

Primary source: https://github.com/rsms/inter/releases/tag/v4.1

Download: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Retrieved October 13, 2026. Only extras/ttf/Inter-Regular.ttf,
extras/ttf/Inter-SemiBold.ttf, extras/ttf/Inter-Bold.ttf and LICENSE.txt were retained
from the 33,707,794-byte release archive. The transient archive was removed after
extraction. No variable font conversion, third-party repackaging or system font
installation was performed.
